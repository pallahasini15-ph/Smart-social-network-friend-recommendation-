SMART SOCIAL NETWORK - SEPARATE FILE VERSION

Files:
main.c
social_network.h
users.c
graph.c
bfs.c
dfs.c
recommendation.c
file_handling.c

Compile in VS Code terminal:
gcc main.c users.c graph.c bfs.c dfs.c recommendation.c file_handling.c -o social

Run on Windows:
.\social

Run on Linux/macOS:
./social

The program uses:
Structures, linked lists, graphs, adjacency lists, queue, BFS, DFS,
searching, sorting and file handling.

Recommendation score:
Score = (Mutual Friends * 10) - Social Distance

AI/Python is an optional extension after the C project is complete.
